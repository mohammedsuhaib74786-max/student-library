# Library Management System

## Introduction
The Library Management System is a web-based application used to track book inventory, manage student memberships, and record book issue and return transactions.

## Features
- Add, update, and search books in the library catalog
- Student and member registration
- Issue and return books
- Track book availability and due dates
- Overdue fine calculation and borrowing history reports

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Download the project.
2. Open the project folder.
3. Open index.html in a browser.

## Usage
1. Login to the system as an admin or librarian.
2. Search for a book by title, author, or ISBN.
3. Select a student and issue the book.
4. Process returns and generate borrowing reports.

## Future Enhancements
- Barcode/QR code scanner integration for fast book checkout
- Automated email reminders for overdue books
- Cloud database and student mobile portal
